# Reinforcement Learning Foundations

An interactive course on **what an agent is trying to do, and how you would check the answer**, built around

> Richard S. Sutton and Andrew G. Barto,
> *Reinforcement Learning: An Introduction* (second edition),
> MIT Press, 2018,

together with the derivations of

> OpenAI, *Spinning Up in Deep RL*, an online course with reference implementations,

and the bootstrap estimator of

> Gert Williams and Christopher J. C. Burges,
> *Asymptotic Confidence Bounds for the Monte Carlo Estimation of the Value Function: A Bootstrap Approach*,
> Machine Learning 8, 375–389, 1990.

The site is a real learning environment: a source-mapped curriculum, four laboratories that run real algorithms, a
glossary whose dependencies are a checked directed acyclic graph, an equation reference with derivations and worked
examples, and a graded assessment bank.

> **Everything here is a teaching instrument.** The environment is a gridworld generated by this site's own code, and
> every value function, gradient and advantage is computed from it — most of them by iteration, so the answers are
> exact. No environment, dataset or trained model is downloaded, and no data leaves the browser.

## What is in the course

### The curriculum (4 modules, 8 lessons)

| Module | Lessons | Source |
| --- | --- | --- |
| **The MDP** | States and returns | Sutton & Barto §3; Spinning Up §2 |
| **Value functions** | The value function · The optimal policy | Sutton & Barto §4, §6, §9 |
| **Policy gradients** | The likelihood-ratio trick | Sutton & Barto §13; Spinning Up §3 |
| **Actor–critic** | The baseline · The n-step return · The λ-return · The actor–critic loop | Sutton & Barto §5, §13; Williams & Burges §1; Spinning Up §4 |

Every lesson names the section of the paper it was written from, and the test suite refuses a lesson that cites a
section which is not in the source map.

### The four laboratories

| Lab | What you can change | What you can measure |
| --- | --- | --- |
| **A · The gridworld** | The accuracy of a move, the step reward, the goal reward | The transition kernel, the value of every state, the sweep-by-sweep convergence, the optimal policy, and the return of a real episode |
| **B · The policy gradient** | The number of trajectories, how far the policy is from uniform, the baseline | The estimate against the exact gradient of the exact expected return, the relative error, and the spread of the estimate with and without a baseline |
| **C · The returns** | λ, the horizon, the discount | The n-step returns of a real episode, the measured bias and variance of the advantage estimate, and the advantage against the truth |
| **D · The actor–critic loop** | The episodes, the two learning rates, the discount, the baseline | The learning curve, what the learned policy is worth against the random and the optimal ones, and the critic's gap |

### The rest of the course

- **Practice** — 15 questions with per-option feedback, worked explanations and source citations.
- **Glossary** — 19 terms, each with a plain-language definition and the terms that should be understood first. The
  dependency graph is checked for cycles.
- **Equations** — 8 results with the source, the plain-language meaning, every symbol, the assumptions, a derivation
  and a worked example.
- **Sources** — every work cited, with the licence it was verified under, and the section map of each source.

## The rule this course follows

**Every number is computed, and nothing is faked.**

The algorithms live in `src/core/` as pure functions with no DOM and no framework. They are unit-tested in Node,
without a browser, and the interface renders what those functions return.

### The answers are exact, and the estimates are checked against them

This course is unusual in that the right answer is *computable*. The gridworld is small enough that:

- the value function is found by iteration, and the test suite checks that it satisfies the Bellman equation;
- the expected return of a parameterised policy is computed exactly, and the policy gradient is compared against a
  **central finite difference** of it — the estimator has to converge to the real gradient;
- the true advantage of every state and action is computed by iteration, and the λ-return and the general advantage
  estimate are measured against it, so the bias and the variance are *measured* rather than asserted.

## Project layout

```
src/
  core/            the algorithms — pure functions, no React, no DOM
    mdp.ts            the gridworld, the kernel, value iteration, the policy
    policygradient.ts the estimator, the exact gradient, the baseline
    returns.ts        the n-step return, the λ-return, the general advantage
    actorcritic.ts    the loop, the learning curves, the critic's gap
  content/         the course: curriculum, glossary, quiz, equations, sources
  components/lab/  the four laboratories
  pages/           one file per route
  test/            test setup
e2e/               Playwright specs, including the axe-core audit
docs/              sources and licensing
```

The shared interface layer lives in `@llm-materials/course-ui`, the numerical core in `@llm-materials/course-core`, and
the collection-wide catalogue in `@llm-materials/course-catalogue`. The rule is unchanged: **numbers are computed in
`src/core`, never in a component.**

## Accessibility

- An **axe-core audit** runs over fourteen pages in the browser suite, in both the light and the dark theme, and fails
  the build on any `wcag2a`, `wcag2aa`, `wcag21a` or `wcag21aa` violation.
- Every tab strip implements the WAI-ARIA tab pattern; charts carry a name, a caption and a data-table alternative;
  the theme is applied before the first paint.
- `/` opens the course search and `Escape` closes it.
