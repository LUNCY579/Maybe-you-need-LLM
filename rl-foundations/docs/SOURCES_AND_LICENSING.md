# Sources and licensing

This course is written from three works and one shared package. None of them is redistributed: they are cited by
chapter and section, linked to their canonical record, and every figure in the course is an original plot of a
computation made in the browser.

---

## The works cited

### 1. The primary source

**Reinforcement Learning: An Introduction (second edition)**
Richard S. Sutton, Andrew G. Barto
MIT Press, 2018. The authors publish the complete PDF free of charge for personal use.
<http://incompleteideas.net/book/the-book-2nd.html>

Everything the course is *about* comes from here: the Markov decision process, the value function, the Bellman
equations, dynamic programming, the policy gradient theorem, the baseline, and the actor–critic family.

- **Licence.** The book is distributed free of charge by the authors for personal use. The machine-check could not be
  completed from this environment — a TLS trust failure on the host — so the terms are recorded from the canonical
  page rather than verified. **Read the terms on the page itself before reusing anything.**
- **What this course uses.** The definitions, the equations, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The book's figures, its exercises, its worked examples, and its text. Every
  definition, every equation and every algorithm here is written out in the course's own words, and every number is
  computed by the course's own code.

### 2. The derivations

**Spinning Up in Deep RL**
OpenAI, 2019. An online course with reference implementations.
<https://spinningup.openai.com/>

- **Licence.** MIT (verified via the GitHub API for `openai/spinningup`, 2026-10-19).
- **Used for.** The likelihood-ratio trick, the policy gradient theorem, the estimators that follow from it, and the
  actor–critic family.
- **Not used.** Any figure, any code, or any text. The derivations are cited by section and worked out here.

### 3. The bootstrap estimator

**Asymptotic Confidence Bounds for the Monte Carlo Estimation of the Value Function: A Bootstrap Approach**
Gert Williams, Christopher J. C. Burges
Machine Learning 8, 375–389, 1990
<https://link.springer.com/article/10.1007/BF00983696>

- **Licence.** Springer article. Bibliographic reference only; the text is not redistributed.
- **Used for.** The λ-return, the general advantage estimate, and the variance–bias trade-off they make. The estimator
  is implemented from the published definition in the course.
- **Not used.** Any figure, any table, or any code.

### 4. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The seeded random number generator, the linear algebra, the statistics, and the assessment engine.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset and no third-party code
from any cited work appears in this repository. Where the course needs to show something a book showed, the result is
named, the source is cited, and the page says plainly that it is quoted rather than computed.

**It uses no dataset and no environment.** The gridworld is generated by this course's own code, with the seed shown
on screen, and every value function, gradient and advantage is computed from it.

**It trains no large model.** The policy is a table of logits and the critic is a table of values. Both are learned in
your browser, from scratch, every time you change a setting.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The optimal value, the exact gradient, the true advantage | "the optimal value", "the exact gradient" |
| Measured | The estimated gradient, the bias, the speed-up | "the estimate", "the measured bias" |
| Quoted | A result named in a book | The source is named next to the number |

## A note on versions

The book is a fixed edition, so there is nothing to re-check there. The arXiv papers in the wider collection are
versioned, and the catalogue records the version each one was read at.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
