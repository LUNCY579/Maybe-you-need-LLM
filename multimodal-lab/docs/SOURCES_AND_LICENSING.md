# Sources and licensing

This course is written from six papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

---

## The works cited

### 1. The primary source

**Learning Transferable Visual Models From Natural Language Supervision**
Alec Radford, Jong Wook Kim, Chris Hallacy, Aditya Ramesh, Gabriel Goh, Sandhini Agarwal and others
arXiv:2103.00020 [cs.CV] / ICML 2021
<https://arxiv.org/abs/2103.00020>

Everything the course is *about* comes from here: the contrastive objective, the in-batch negatives, the temperature,
the precomputed index, and the zero-shot transfer.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the method, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The paper's figures, its models, its dataset, and its text. **No image and no
  dataset is redistributed here**: the pairs in this course are generated by the course's own code.

### 4. The sigmoid loss

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset, no example and no model
from any cited work appears in this repository. The image–caption pairs, the classes and the instructions are all
generated by the course's own code, with the seed shown.

**It analyses no real model.** The encoders here are matrices over one-hot inputs, trained in the browser. The sigmoid
and frozen-bridge laboratories go further and are hand-wired toys: the logits are synthetic, the attention comes from
seeded vectors, and the parameter bill is an accounting stated with its assumptions next to it. What the course
teaches is the *method* — the loss, the batch, the gap, the zero-shot classifier, the tax, the coupling, and the
bridge — and each of those is a step a practitioner does anyway.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The gradient of the contrastive loss, the balance condition | "the gradient", "the loss" |
| Measured | The retrieval, the gap, the tax | "the retrieval", "the measured gap" |
| Synthetic | The sigmoid laboratory's logits, the frozen bridge's attention | "synthetic", "a toy", "hand-wired" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2103.00020**, and against the current PDF of arXiv:2303.15343 (v3) for the sigmoid lesson's section
numbers. If you reuse anything from these works, cite the version you used and check that version's licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
