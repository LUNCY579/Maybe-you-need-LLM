# Sources and licensing

This course is written from four papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

---

## The works cited

### 1. The primary source

**FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness**
Tri Dao, Daniel Y. Fu, Fangcheng Chiang, Quoc V. Le
arXiv:2205.14135 [cs.LG] / NeurIPS 2022
<https://arxiv.org/abs/2205.14135>

Everything the course is *about* comes from here: the memory-hierarchy argument, the tiling, the online softmax, the
exactness of the result, and the recomputation in the backward pass.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the algorithm, the structure of the argument, and the accounting.
- **What this course does not use.** The paper's figures, its benchmarks, and its text. No figure from the paper
  appears anywhere in the application.

### 2. The paged allocator

**Efficient Memory Management for Large Language Model Serving with PagedAttention**
Woosuk Kwon, Zhuohan Li, Siyuan Zhuang, Ying Sheng, Lianmin Zheng and others
arXiv:2309.06180 [cs.DC] / SOSP 2023
<https://arxiv.org/abs/2309.06180>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The serving problem, the key and value cache, the arithmetic intensity of a decode step, the page
  table, and the fragmentation the paging removes.
- **Not used.** Any figure, any throughput number, or any code.

### 3. Sparse capacity

**GShard: Scaling Giant Models with Conditional Computation and Automatic Sharding**
William Shen, Yanyong Wang, Yizhong Wang, Ye Yuan, Zhihao Deng and others
arXiv:1701.06538 [cs.LG] / ICLR 2017
<https://arxiv.org/abs/1701.06538>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The top-k router, the capacity factor, the tokens that overflow, and the auxiliary loss that keeps the
  experts balanced.
- **Not used.** Any figure, any training result, or any code.

### 4. Speculation

**SpecInfer: Accelerating Generative Large Language Model Serving with Tree-based Speculative Inference and Verification**
Charlie Chen, Sebastian Borgeaud, Geoffrey Irving, Jean-Baptiste Alayrac, Mohammad Ostadi and others
arXiv:2305.09781 [cs.DC] / ICASSP 2024
<https://arxiv.org/abs/2305.09781>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The draft, the verification, the acceptance rule, and the exactness of the output distribution.
- **Not used.** Any figure, any speed-up measurement, or any code.

### 5. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The seeded random number generator, the linear algebra, the statistics, and the assessment engine.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset and no third-party code
from any cited work appears in this repository. Where the course needs to show something a paper showed, the result is
named, the source is cited, and the page says plainly that it is quoted rather than computed.

**It runs no transformer.** The laboratories use a model *shape* and account for what a program of that shape would
cost. The attention is real and is checked against the naive implementation; the decode step is accounted for rather
than executed; the router and the verification are real algorithms run on synthetic inputs.

**It uses no dataset.** The matrices, the embeddings, the distributions and the sequences are generated by this
course's own code, with the seed shown on screen.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The acceptance rule, the size of the cache, the attention's answer | "the acceptance rule", "the cache" |
| Measured | The memory the attention used, the auxiliary loss, the speed-up | "measured", "the loss" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2205.14135**. If you reuse anything from it, cite the version you used and check that version's
licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
