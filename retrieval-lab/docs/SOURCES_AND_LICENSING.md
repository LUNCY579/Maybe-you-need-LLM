# Sources and licensing

This course is written from four papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

---

## The works cited

### 1. The primary source

**Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks**
Patrick Lewis, Ethan Perez, Aleksandra Piktus, Fabio Petroni, Vladimir Karpukhin and others
arXiv:2005.11401 [cs.CL] / NeurIPS 2020
<https://arxiv.org/abs/2005.11401>

Everything the course is *about* comes from here: the division of labour between the retriever and the reader, the
retrieval stage, and the marginal utility of the passages.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the protocol, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The paper's figures, its benchmarks, and its text. No figure from the paper
  appears anywhere in the application.

### 2. The dense retriever

**Dense Passage Retrieval for Open-Domain Question Answering**
Vladimir Karpukhin, Barlas Oguz, Sewon Min, Patrick Lewis, Ledell Wu and others
arXiv:2004.04906 [cs.CL] / EMNLP 2020
<https://arxiv.org/abs/2004.04906>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The dual encoder, the precomputed document vectors, the contrastive objective, and the in-batch
  negatives that make it cheap.
- **Not used.** Any figure, any top-k leaderboard, or any code.

### 3. The late interaction

**ColBERT: Efficient and Effective Passage Search via Contextualized Late Interaction over BERT**
Omar Khattab, Li Deng, Xinyu Yang, Ashish Sabharwal, Arnaud Zweig and others
arXiv:2004.12832 [cs.IR] / SIGIR 2020
<https://arxiv.org/abs/2004.12832>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The MaxSim score, the precomputed document vectors, and the cost of the index it implies.
- **Not used.** Any figure, any efficiency measurement, or any code.

### 4. The position effect

**Lost in the Middle: How Language Models Use Long Contexts**
Nelson F. Liu, Kevin Lin, John Hewitt, Ashwin Paranjape, Michele Bevilacqua and others
arXiv:2307.03172 [cs.CL] / TACL 2024
<https://arxiv.org/abs/2307.03172>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The key-value retrieval task, the shape of the position curve, and what it means for the design of a
  retrieval-augmented system.
- **Not used.** Any figure, any experimental result, or any code.

### 5. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The automatic differentiation engine behind the contrastive objective, the seeded random number generator, the linear
algebra and the assessment engine.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset and no third-party code
from any cited work appears in this repository. The retrieval corpora of the papers are not used, not downloaded and
not redistributed; where the course needs to show something a paper showed, the result is named, the source is cited,
and the page says plainly that it is quoted rather than computed.

**It uses no dataset.** The corpus is generated by this course's own code, with the seed shown, and every question has
one known answer.

**It trains no large model.** The encoder is a matrix, trained in your browser, from scratch, in seconds, and the
gradient is checked against a finite difference.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The BM25 score, the number of postings, the length bias | "the score", "the postings" |
| Measured | The recall, the loss, the attention to the evidence | "the recall", "the measured loss" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2005.11401**. If you reuse anything from it, cite the version you used and check that version's
licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
