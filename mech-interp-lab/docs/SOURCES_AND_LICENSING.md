# Sources and licensing

This course is written from three works and one shared package. None of them is
redistributed: they are cited by section, linked to their canonical record, and every
figure in the course is an original plot of a computation made in the browser.

---

## The works cited

### 1. The primary source

**Sparse Autoencoders Find Highly Interpretable Features in Language Models**
Hoagy Cunningham, Aidan Ewart, Logan Riggs, Robert Huben, Lee Sharkey
arXiv:2309.08600 [cs.LG] / ICLR 2024
<https://arxiv.org/abs/2309.08600>

Everything the course is *about* comes from here: the toy model of superposition, the
interference it costs, the sparse autoencoder and its objective, the scoring of a
dictionary feature's interpretability, and the patching procedure adapted to dictionary
features.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative
  Commons licence is shown on the record.
- **What this course uses.** The definitions, the loss functions, the structure of the
  argument, and the design of the measurement experiments.
- **What this course does not use.** The paper's figures, its tables of feature
  scores, and its text. No figure from the paper appears anywhere in the application.

### 2. The workflow

**Towards Automated Circuit Discovery for Mechanistic Interpretability**
Arthur Conmy, Augustine N. Mavor-Parker, Aengus Lynch, Stefan Heimersheim, Adrià Garriga-Alonso
arXiv:2304.14997 [cs.LG]
<https://arxiv.org/abs/2304.14997>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The four steps of the mechanistic-interpretability workflow, the
  definition of a circuit, the activation-patching procedure, the attribution-patching
  algorithm, and the faithfulness score.
- **Not used.** Any figure, any table of recovered circuits, or any code.

### 3. The framework

**A Mathematical Framework for Transformer Circuits**
Noah Elhage, Tristan Hume, Shan Carter, Scott Ostheim, Scott Linderman and others
transformer-circuits.pub — a public web publication
<https://transformer-circuits.pub/2021/framework.html>

- **Licence.** A public web publication. The machine-check from the environment this
  course was built in was blocked by the site, so the terms have **not** been verified
  here; read them on the page itself before reusing any text or figure.
- **Used for.** The residual stream, and the vocabulary of nodes, edges and paths that
  a circuit is made of.
- **Not used.** Any figure, any text, or any code.

### 4. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The automatic differentiation engine that trains the sparse autoencoder in Laboratory B,
the seeded random number generator, the linear algebra, and the assessment engine.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no
dataset and no third-party code from any cited work appears in this repository. Where
the course needs to show something a paper showed — the loss of the toy model, the
shape of the sparse autoencoder's objective — the result is named, the source is cited,
and the page says plainly that it is quoted rather than computed.

**It analyses no real model.** The model in Laboratory A is the *toy model of
superposition*: a linear map with independent features and a known loss. It is a
measuring instrument for the phenomenon, not a transformer, and it is not any published
model. The circuit in Laboratory C is a synthetic graph with a known computation in it.

**It trains no model for you.** The sparse autoencoder in Laboratory B is trained in
your browser, from scratch, every time you press the button. There is no checkpoint to
download and nothing is fetched.

**It uses no dataset.** Every feature, every activation and the circuit itself are
generated by the course's own code, with the seed shown on screen, so that any figure
can be reproduced exactly.

**It calls nothing.** There is no API key, no network request and no telemetry. The
build is a static bundle that works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser,
drawn by the course's own chart code from the numbers the course's own algorithms
return. No figure from any cited work is reproduced, traced or adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The toy model's loss, its analytic gradient, the participation ratio | "the loss", "the analytic gradient" |
| Measured | The fitted interference, the trained autoencoder's error, the patched effect | "measured, on …", "the model computes" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between
versions. This course was written against **arXiv:2309.08600**. If you reuse anything
from it, cite the version you used and check that version's licence.

The catalogue of every source across every course in this collection lives in the
workspace at `references/manifest.json`, and is validated by a script that re-reads
every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
