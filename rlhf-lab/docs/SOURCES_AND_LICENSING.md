# Sources and licensing

This course is written from four papers. None of them is redistributed: they are cited
by chapter, section and equation, linked to their canonical record, and every figure in
the course is an original plot of a computation made in the browser.

---

## The works cited

### 1. The primary source

**The N+ Implementation Details of RLHF with PPO: A Case Study on TL;DR Summarization**
Shengyi Huang, Michael Noukhovitch, Arian Hosseini, Kashif Rasul, Weixun Wang, Lewis Tunstall
arXiv:2403.17031 [cs.LG] / COLM 2024
<https://arxiv.org/abs/2403.17031>

Everything the course is *about* comes from here: the three stages of the pipeline, the
enumerated implementation details, the KL estimator and coefficient, and the reproduced
scaling behaviours.

- **Licence.** **CC BY 4.0** on the OpenReview record
  (<https://openreview.net/forum?id=kHO2ZTa8e3>). The arXiv copy carries the arXiv
  perpetual, non-exclusive distribution licence.
- **What this course uses.** The definitions, the protocol, the structure of the
  argument, and the design of the measurement experiments.
- **What this course does not use.** The paper's figures, its tables, its checkpoints and
  its text. No figure from the paper appears anywhere in the application.

### 2. The clipped objective

**Proximal Policy Optimization Algorithms**
John Schulman, Filipe Wolski, Prafulla Dhariwal, Alec Radford, Oleg Klimov
arXiv:1707.06347 [cs.LG]
<https://arxiv.org/abs/1707.06347>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The clipped surrogate objective, the clip fraction, and the reason the
  clip removes the incentive to move rather than merely shrinking the step.
- **Not used.** Any figure or any code.

### 3. The trust region

**Trust Region Policy Optimization**
John Schulman, Sergey Levine, Philipp Moritz, Michael I. Jordan, Pieter Abbeel
arXiv:1502.05477 [cs.LG] / ICML 2015
<https://arxiv.org/abs/1502.05477>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The trust-region constraint, the natural gradient, and the
  conjugate-gradient step that the clip is a cheap approximation to.
- **Not used.** Any figure or any code.

### 4. The overoptimisation result

**Scaling Laws for Reward Model Overoptimization**
Leo Gao, John Schulman, Jacob Hilton
arXiv:2210.10760 [cs.LG] / ICLR 2023
<https://arxiv.org/abs/2210.10760>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The overoptimisation result, the two functional forms, and the
  comparison between best-of-n and reinforcement learning.
- **Not used.** Any figure or any empirical result.

### 5. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The seeded random number generator, the softmax and log-softmax, the normal quantiles
and the bootstrap behind every number in this course.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no
dataset, no checkpoint and no third-party code from any cited work appears in this
repository.

**It trains no language model.** The policy in every laboratory is a softmax over at
most a few dozen logits, written out in full so that every gradient can be checked by
hand. The reward model is a generated quadratic with an injected slope and a fixed
random wiggle.

**It uses no dataset.** Every problem is generated by the course's own code, with the
seed shown on screen.

**It calls nothing.** There is no API key, no network request and no telemetry. The
build is a static bundle that works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser,
drawn by the course's own chart code from the numbers the course's own algorithms
return. No figure from any cited work is reproduced, traced or adapted.

The course distinguishes three kinds of number on screen, and says which is which:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The expected reward of a policy, the closed form of a divergence | "This is exact" |
| Measured | The gradient check, the agreement of an estimator, the overoptimisation curve | "Measured, on …" |
| Quoted | The paper's reported behaviours | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between
versions. This course was written against **arXiv:2403.17031**. If you reuse anything
from it, cite the version you used and check that version's licence.

The catalogue of every source across every course in this collection lives in the
workspace at `references/manifest.json`, and is validated by a script that re-reads
every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
