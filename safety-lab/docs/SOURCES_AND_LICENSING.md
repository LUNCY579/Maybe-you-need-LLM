# Sources and licensing

This course is written from six papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

The author lists below are the ones on each paper's live arXiv record — the first six names, then *et al.* — and the
same names are what `src/content/sources.ts` renders on the Sources page. The collection keeps a live copy in
`references/manifest.json`, which `npm run validate:sources:live` re-reads from arXiv.

## The works cited

### 1. The primary source

**Constitutional AI: Harmlessness from AI Feedback**
Yuntao Bai, Saurav Kadavath, Sandipan Kundu, Amanda Askell, Jackson Kernion, Andy Jones et al.
arXiv:2212.08073 [cs.CL] / Anthropic, 2022
<https://arxiv.org/abs/2212.08073>

Everything the course is *about* comes from here: the critique-and-revise loop, the preference data it makes, and the
discussion of what a harmlessness claim does not establish.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the method, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The paper's figures, its examples, its model, and its text. Every example here is
  generated by the course's own code.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset, no prompt and no example
from any cited work appears in this repository. The exchanges, the attacks, the label sheets, the questions and the
training records are all generated by the course's own code, with the seed shown.

**It evaluates no model.** Every "model" here is a rule over a generated task: a table of responses with a principle
that names the violation, a least-squares fit over cue features, a seeded sampler over a taxonomy, a per-record
probability set by how often that record was seen. What the course teaches is the *measurement* — the agreement of a
judge, the coverage of a red team, the gap between the harm an evaluation reports and the harm there is, the flip rate,
the exposure — and each of those is a number a safety paper should report.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The agreement, the coverage, the flip rate | "the agreement", "the coverage" |
| Measured | The harm after the loop, the exposure, the success rate | "the measured", "the exposure" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2212.08073**, **2204.05862**, **2202.03286**, **2401.05566**, **2310.13548** and **2012.07805**. If you
reuse anything from it, cite the version you used and check that version's licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
