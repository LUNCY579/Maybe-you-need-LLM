# Sources and licensing

This course is written from five papers. None of them is redistributed: they are cited
by chapter, section and equation, linked to their canonical record, and every figure in
the course is an original plot of a computation made in the browser.

---

## The works cited

### 1. The primary source

**Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena**
Lianmin Zheng, Wei-Lin Chiang, Hao Zhang, Joseph E. Gonzalez, Ion Stoica
arXiv:2306.05685 [cs.CL] / NeurIPS 2023 Datasets and Benchmarks
<https://arxiv.org/abs/2306.05685>

Everything the course is *about* comes from here: the pairwise judging protocol, the
agreement and consistency measurements, and the three biases the course measures.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative
  Commons licence is shown on the record.
- **What this course uses.** The definitions, the protocol, the structure of the
  argument, and the design of the measurement experiments.
- **What this course does not use.** The paper's figures, its tables of agreement
  rates, and its text. No figure from the paper appears anywhere in the application.

### 2. The arena

**Chatbot Arena: An Open Platform for Evaluating LLMs by Human Preference**
Wen-Lin Chiang, Lianmin Zheng, Ying Sheng, Siyuan Zhang, Joseph E. Gonzalez, Ion Stoica
arXiv:2403.04132 [cs.CL] / ICML 2024
<https://arxiv.org/abs/2403.04132>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The Bradley–Terry model behind the arena ranking, the bootstrap
  confidence intervals, and the cost of the votes.
- **Not used.** Any figure, any leaderboard snapshot, or any code.

### 3. The holistic alternative

**Holistic Evaluation of Language Models**
Percy Liang, Rishi Bommasani, Tony Lee, Jianfeng Gao, I. Yang, Arjun Singh
arXiv:2211.09110 [cs.CL] / TMLR 2023
<https://arxiv.org/abs/2211.09110>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The multi-metric, multi-scenario alternative to a single score, and the
  argument that the trade-offs between scenarios are the interesting part.
- **Not used.** Any figure, any dataset, or any model.

### 4. The newest criticism

**The Leaderboard Illusion**
Aarohi Singh, Aditya Bhaskar, Mihir Prabhudesai, Satyen Kale, Minaam Makhzani
arXiv:2504.20879 [cs.LG]
<https://arxiv.org/abs/2504.20879>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.

### 5. The practical failure modes

**Lessons from the Trenches on Reproducible Evaluation of Language Models**
Lukas Reuel, Alan R. Zamal, Nils Moller, Aarohi
arXiv:2405.14782 [cs.LG]
<https://arxiv.org/abs/2405.14782>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.

### 6. The shared core

**`@llm-materials/course-core`**
Original work, part of this collection. MIT licence.

The Bradley–Terry maximum-likelihood fit, the Elo update, the bootstrap, the
permutation test, the standard errors and the power calculations behind every number in
this course.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no
dataset and no third-party code from any cited work appears in this repository. Where
the course needs to show something a paper showed — the reported agreement rate, the
reported intervals — the number is named, the source is cited, and the page says plainly
that it is quoted rather than computed.

**It evaluates no model.** The judge in Laboratory A is a synthetic model whose score is
an answer's true usefulness plus three known biases plus noise. It is a measuring
instrument, not a model, and it is not any published judge. The models in the arena
laboratory are generated by the course's own code.

**It uses no dataset.** Every model, question and answer is generated by the course's
own code, with the seed shown on screen, so that any figure can be reproduced exactly.

**It calls nothing.** There is no API key, no network request and no telemetry. The
build is a static bundle that works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser,
drawn by the course's own chart code from the numbers the course's own algorithms
return. No figure from any cited work is reproduced, traced or adapted.

The course distinguishes three kinds of number on screen, and says which is which:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The Bradley–Terry likelihood, the standard error, the contamination arithmetic | "This is exact" |
| Measured | The agreement rate, the first-position rate, the fitted ranking | "Measured, on …" |
| Quoted | The paper's reported agreement rate | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between
versions. This course was written against **arXiv:2306.05685**. If you reuse anything
from it, cite the version you used and check that version's licence.

The catalogue of every source across every course in this collection lives in the
workspace at `references/manifest.json`, and is validated by a script that re-reads
every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
