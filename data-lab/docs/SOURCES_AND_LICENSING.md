# Sources and licensing

This course is written from four papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

---

## The works cited

### 1. The primary source

**DataComp: In search of the next generation of multimodal datasets**
Florian Muennighoff, Alexander M. Rush, Boaz Barak, Tianyi Zhang, Ethan Caballero
arXiv:2304.14108 [cs.CV] / NeurIPS 2023 Datasets and Benchmarks
<https://arxiv.org/abs/2304.14108>

Everything the course is *about* comes from here: the framing of filtering as a benchmark, the pipeline, the CLIP
filtering, and the ablation table that scores every filter by the model trained on what survives it.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the protocol, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The paper's figures, its leaderboard tables, its datasets, and its text. No
  figure from the paper appears anywhere in the application.

### 2. The pipeline

**The RefinedWeb Dataset for Falcon LLM: Outperforming Curated Corpora with Web Data, and Web Data Only**
Guillaume Penedo, Qinglu Xiao, Alexandro Pouget-Abadie and others
arXiv:2306.01116 [cs.CL]
<https://arxiv.org/abs/2306.01116>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.
- **Used for.** The Midas filtering pipeline and the order of its stages, the reference model and the perplexity
  filter, the three kinds of deduplication, and the per-stage ablation table.
- **Not used.** Any figure, the dataset itself, the model, or any code.

### 3. The mixture

arXiv:2305.10429 [cs.LG] / NeurIPS 2023

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset and no third-party code
from any cited work appears in this repository. The datasets of DataComp, RefinedWeb and Dolma are not used, not
downloaded and not redistributed; where the course needs to show something a paper showed, the result is named, the
source is cited, and the page says plainly that it is quoted rather than computed.

**It trains on no real data.** The corpus in every laboratory is generated by this course's own code: a Markov chain
over a small vocabulary, with boilerplate, foreign text and near-duplicates mixed in at known rates. The seed is shown
on screen, so any figure can be reproduced exactly.

**It evaluates no published model.** The classifier is a multinomial logistic regression trained in the browser, from
scratch, on the generated corpus. It is not any published model and it is not a benchmark result.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The perplexity of a document, the Jaccard similarity, the closed-form mixture | "the perplexity", "the similarity" |
| Measured | The fitted interference, the trained classifier's accuracy, the patched effect | "measured, on …", "the model computes" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2304.14108**. If you reuse anything from it, cite the version you used and check that version's
licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
