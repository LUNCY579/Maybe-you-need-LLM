# Sources and licensing

This course is written from four papers and one shared package. None of them is redistributed: they are cited by
section, linked to their canonical record, and every figure in the course is an original plot of a computation made in
the browser.

---

## The works cited

### 1. The primary source

**SWE-bench: Can Language Models Resolve Real-World GitHub Issues?**
Carlos E. Jimenez, Steven Pombra, Alexander M. Agarwal, Kalyan Ankala, Sudipta Ganguli, Yuning Zhou, Kiran Prasad et al.
arXiv:2310.06770 [cs.SE] / ICLR 2024
<https://arxiv.org/abs/2310.06770>

Everything the course is *about* comes from here: the tasks, the evaluation criterion, the agentless baseline, and the
discussion of variance and contamination.

- **Licence.** The arXiv perpetual, non-exclusive distribution licence. No Creative Commons licence is shown on the
  record.
- **What this course uses.** The definitions, the criterion, the structure of the argument, and the design of the
  measurement experiments.
- **What this course does not use.** The paper's figures, its leaderboards, its dataset, and the repositories, issues
  and test suites it is built from. **No repository, issue or test is redistributed here**: the tasks in this course are
  generated by the course's own code.

### 2. The question design

arXiv:2311.12983 [cs.AI] / ICLR 2024
<https://arxiv.org/abs/2311.12983>

- **Licence.** arXiv perpetual, non-exclusive distribution licence.

## What this course does not do

**It redistributes no source material.** No PDF, no figure, no table, no image, no dataset, no repository, no issue and
no test suite from any cited work appears in this repository. The tasks, the repositories, the tests and the training
corpus are all generated by the course's own code, with the seed shown.

**It resolves no real issue.** The tasks are synthetic and the solvers are rules over them. What the course teaches
is the method — the interval, the criterion, the baseline, the contamination test — and every step of it is a
measurement rather than an opinion.

**It calls nothing.** There is no API key, no network request and no telemetry. The build is a static bundle that
works from the file system.

## Figures

Every figure in this course is an original plot of a computation made in the browser, drawn by the course's own chart
code from the numbers the course's own algorithms return. No figure from any cited work is reproduced, traced or
adapted.

The course distinguishes three kinds of number on screen, and says which is each:

| Kind | Example | Statement on screen |
| --- | --- | --- |
| Exact | The Wilson interval, the pass@k estimate, the overlap | "the interval", "the estimate" |
| Measured | The score, the spread across runs, the rates | "the score", "the measured overlap" |
| Quoted | A result named in a paper | The source is named next to the number |

## A note on versions

An arXiv licence is attached to a specific submission, and it can change between versions. This course was written
against **arXiv:2310.06770**. If you reuse anything from it, cite the version you used and check that version's
licence.

The catalogue of every source across every course in this collection lives in the workspace at `references/manifest.json`,
and is validated by a script that re-reads every arXiv title live:

```bash
node scripts/validate-sources.mjs --verify
```
